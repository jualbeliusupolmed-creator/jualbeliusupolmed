[USER] <-> [NEXT.JS APP (Vercel)] <---> [SUPABASE (Postgres/Auth/Storage)] | | (Edge Functions) | +---> [GOOGLE GEMINI API (Moderasi)] | +---> [VPS (PM2 + Baileys Bot)] <---> [WhatsApp Server]

Detail Integrasi

1. Frontend & API (Next.js 14 App Router)

Berjalan di Vercel. Menggunakan App Router untuk SSR (Server Side Rendering). API routes di src/app/api/ berperan sebagai jembatan antara user dan Supabase.

2. Supabase (Database & Backend)

Menggunakan service_role di sisi server untuk bypass RLS (Row Level Security). RLS hanya aktif untuk akses langsung dari client menggunakan Anon Key.

3. Moderasi (Layer AI)

Sebelum masuk ke database, data dilewatkan ke src/lib/moderationRules.js. Integrasi GoogleGenerativeAI (Gemini) mendeteksi barang terlarang (vape, senjata, dll) dengan timeout 6 detik untuk performa.

4. WhatsApp Bot (Eksternal VPS)

Bot berjalan terpisah di VPS menggunakan Baileys. Sinkronisasi dilakukan lewat polling atau webhooks database. Bot ini bertindak sebagai:

  • Penyebar konten (Broadcast)
  • Pusat transaksi (notifikasi pesanan)

Alur Detil Pasang Iklan

  1. Input: User kirim data form ke POST /api/listings.
  2. Auth: Middleware & `getSellerSessionAsync` verifikasi sesi WA (HMAC signed token).
  3. Schema & Moderasi: - Zod validasi input.
    - moderateListing: Pertama cek deterministik (keyword blacklisted), lalu cek AI (Gemini).
  4. Persistence: Jika lolos, simpan ke listings tabel. Jika tidak, simpan ke log rejected.
  5. Post-Processing: (Async) Jika listing 'active', panggil postToGroup (bot WA), notifikasi subscriber, dan update Instagram via autoPublishListingInstagram.
