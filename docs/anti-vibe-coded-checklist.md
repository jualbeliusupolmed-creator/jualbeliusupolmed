# 30 TANDA WEBSITE VIBE CODED (Checklist Anti Template AI)

Ini adalah checklist agar website tidak terlihat seperti template buatan AI (Vibe Coded). Aturan-aturan ini harus diperhatikan saat mendesain atau memperbarui UI/UX aplikasi Jual Beli USU Polmed.

### 1/ GRADIEN WARNA TERLALU KERAS
- **Tanda AI:** Warna nyala yang tabrakan tanpa alasan (misal: Ungu ke biru ke pink dalam satu tombol).
- **Fix:** Gunakan palet tenang, 2 sampai 3 warna brand, dan pastikan kontras jelas antara teks dan latar.

### 2/ IKON LUCIDE DI MANA-MANA
- **Tanda AI:** Ikon garis tipis di setiap judul walau tidak ada artinya.
- **Fix:** Gunakan ikon hanya untuk membantu *scan* bacaan dengan cepat. Kalau cuma hiasan, hapus.

### 3/ LATAR PUTIH POLOS + KONTRAS LEMAH
- **Tanda AI:** Putih semua, teks abu-abu pucat. Terlihat bersih tapi sulit dibaca (aksesibilitas jelek).
- **Fix:** Teks gelap di latar terang, rasio kontras minimal 4.5:1.

### 4/ WARNA PELANGI
- **Tanda AI:** Merah, kuning, hijau, biru dalam satu halaman.
- **Fix:** Pilih 2 sampai 3 warna brand dan satu aksen. Sisanya warna netral.

### 5/ BAYANGAN JATUH BERLEBIHAN
- **Tanda AI:** Semua elemen dikasih shadow tebal agar terlihat "3D".
- **Fix:** Shadow tipis, hanya untuk elemen yang benar-benar perlu ditonjolkan (naik level).

### 6/ 3 KARTU FITUR SEJAJAR
- **Tanda AI:** Icon + judul + kalimat, tiga kolom sama rata (Layout default generator).
- **Fix:** Pikirkan struktur yang membuat produk menonjol, bukan sekadar rapi.

### 7/ EMOJI DI MANA-MANA
- **Tanda AI:** Emoji di tiap baris sebagai hiasan, bukan info.
- **Fix:** Gunakan emoji hanya jika brand memang memakainya. Jika hanya pengisi, buang.

### 8/ EFEK KACA CAIR (LIQUID GLASS)
- **Tanda AI:** Glassmorphism (blur + transparan) yang sedang tren di template AI.
- **Fix:** Jarang cocok buat bisnis lokal. Pakai hanya kalau ada alasan desain fungsional.

### 9/ TANDA PISAH EM (EM DASHES)
- **Tanda AI:** Kalimat pakai tanda pisah panjang di mana-mana (gaya khas nulis AI).
- **Fix:** Cukup gunakan titik dan koma. Baca ulang secara natural.

### 10/ FONT INTER, GEIST, SPACE GROTESK
- **Tanda AI:** Font AI paling umum.
- **Fix:** Cari font yang punya karakter dan nyambung dengan identitas brand.

### 11/ GARIS WARNA DI SISI KIRI
- **Tanda AI:** Stripe dekoratif di tepi kartu. Rapi tapi tidak informatif.
- **Fix:** Buang. Gunakan hierarki visual sungguhan: ukuran, ketebalan, dan jarak.

### 12/ TESTIMONI PALSU
- **Tanda AI:** Tanpa nama, tanpa foto, tanpa produk jelas (testimonial template).
- **Fix:** 1 testimoni asli lebih baik dari 10 karangan. Gunakan screenshot chat WA pelanggan asli.

### 13/ GRID BENTO
- **Tanda AI:** Kotak-kotak rapi tapi isinya kosong/sedikit.
- **Fix:** Bento grid hanya bagus jika kontennya padat. Kalau tiap kotak cuma 1 kalimat, ganti layout yang lebih simpel.

### 14/ JENDELA TERMINAL DI HERO
- **Tanda AI:** Tampilan kode di halaman depan biar kelihatan tech.
- **Fix:** Audiensnya bukan developer. Tunjukkan produknya langsung.

### 15/ "INI BUKAN X, INI Y"
- **Tanda AI:** Copywriting template: "Bukan aplikasi biasa, ini solusi...".
- **Fix:** Tulis manfaat spesifik buat pelanggan, bukan menggunakan pola puitis/berlebihan.

---
*Catatan: Checklist ini disimpan sebagai panduan desain (UI/UX) untuk pengembangan Jual Beli USU Polmed agar terasa lebih natural, humanis, dan sesuai dengan target pasar lokal.*
