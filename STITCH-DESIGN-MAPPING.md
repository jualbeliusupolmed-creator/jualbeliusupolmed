# STITCH-DESIGN-MAPPING.md

Pemetaan menyeluruh seluruh desain Google Stitch di `stitch_kampus_kita_mobile_redesign/` ke arsitektur frontend **Kampus Kita** (`/Users/ayhoo/Projects/WEBSITE/kampuskita.my.id`).

## Ringkasan Design System Stitch

Dua file `DESIGN.md` di folder Stitch mendefinisikan sistem visual terpadu:
- **Canvas & Surface**: Mint tint `#ecfeee` / `#f4faf5` (mobile), pure white `#ffffff` (`surface-container-lowest`) untuk kartu/kontainer, `#e6f8e8` (`surface-container-low`), `#e0f3e3` (`surface-container`), `#dbeddd` (`surface-container-high`), `#d5e7d8` (`surface-container-highest`).
- **Primary**: Deep Forest Green `#003622` / `#134e35` (`primary-container`), teks di atas primary `#ffffff`.
- **Secondary / Accent**: Electric Lime `#ceeb7a` / `#d7f582` / `#bef264` (`secondary-fixed` / `secondary-container`), teks di atas lime `#161f00` / `#134e35`.
- **Typography**: `Plus Jakarta Sans` (utama di seluruh aplikasi) + `Epilogue` (opsional untuk display/editorial), `Material Symbols Outlined` untuk ikonografi.
- **Navigation Shell**:
  - **Mobile**: Top App Bar sticky (`h-14`, ikon bulat `#134e35` + judul modul + notifikasi + profil) dan **Floating Pill Bottom Navigation** (`fixed bottom-4`, kapsul `#134e35` rounded-full dengan 5 menu: `Jual Beli`, `Open PO`, `LINUSKU`, `Berita`, `Jelajahi`; tab aktif berbentuk kapsul lime `#bef264`/`#d7f582` dengan ikon + label).
  - **Desktop**: Sticky Top Header (`h-20`, `max-w-7xl`), logo Kampus Kita + sublabel, 5-menu pill nav (`bg-surface-container-low p-1 rounded-full`, item aktif `bg-secondary-fixed`), search bar tengah, tombol Chat, Notifikasi, dan Avatar User.
