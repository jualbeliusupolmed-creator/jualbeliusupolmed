Arsitektur Marketplace: KampusKita

1. High-Level Stack

  • Frontend: Next.js 14 (App Router) di Vercel.
  • Backend: Supabase (PostgreSQL, Auth, Storage, Edge Functions).
  • AI: Google Gemini (untuk moderasi konten iklan).
  • WhatsApp Integration: Baileys (running di VPS via PM2).

2. Alur Utama: Pasang Iklan

  1. Form Submit: User isi data di `JualClient.jsx`.
  2. Validasi: Schema validation (Zod) -> Moderasi Deterministik -> AI Moderation (Gemini).
  3. Database: Data masuk ke tabel `listings` (status: `pending` atau `active`).
  4. Distribusi: Jika aktif, fungsi `postToGroup` memicu bot WA untuk menyebar ke grup-grup relevan.

3. Integrasi Detail

  • Supabase: Menjadi satu-satunya sumber kebenaran (Source of Truth). API Routes (Server Side) selalu menggunakan service_role untuk bypass RLS, sedangkan Client menggunakan Anon Key dengan RLS policy yang ketat.
  • WhatsApp Bot (VPS): Bot memantau chat/grup, menyimpan session di VPS, dan berkomunikasi dengan Supabase untuk sinkronisasi iklan/status.
  • Instagram (OAuth): Menggunakan API OAuth untuk integrasi katalog otomatis dan analitik menfess.

4. Penjelasan Komponen

Security Layer: Middleware Next.js menangani proteksi rute admin, sementara Supabase RLS mengamankan data pengguna di level database.

Scalability: Menggunakan Vercel Edge Runtime untuk API ringan dan serverless functions untuk pemrosesan gambar/moderasi.
