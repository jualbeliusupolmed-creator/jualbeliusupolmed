Jual Beli USU Polmed

Satu layanan jual beli, beberapa cara untuk mengaksesnya

Website menangani katalog dan transaksi. Bot WhatsApp membantu pengguna yang ingin memulai dari percakapan.

Bagian sistem

WebsiteAntarmuka marketplace dan API untuk pengalaman jual beli.
Bot WhatsAppPintu percakapan, notifikasi, dan alat operasional.
SupabasePenyimpanan data dan autentikasi layanan sesuai hak akses.

Alur kerja bot

  1. Pengguna memulai perintah bot sesuai pola yang ditetapkan.
  2. Bot meminta informasi yang diperlukan dan meneruskan pekerjaan ke API terkait.
  3. Pengguna menerima hasil atau arahan berikutnya lewat percakapan.
  4. Admin memantau koneksi, antrean, dan kendali operasional melalui panel.
Catatan operasional: detail implementasi dan status endpoint berubah mengikuti kode aktif. Gunakan halaman audit dan riwayat untuk pemeriksaan terbaru.
