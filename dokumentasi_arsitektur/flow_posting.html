  • • Schema Zod (src/lib/listingSchema.js)
  • • Format WA otomatis (parseWaInput)
  • • Kompresi gambar client-side (Sharp WASM)

2

API Gateway & Autentikasi

Request POST dikirim ke /api/listings. Middleware dan handler melakukan serangkaian pemeriksaan keamanan sebelum memproses data.

Rate Limiting

rateLimitDistributed — 10 request per 10 menit per IP. Mencegah spam & brute force.

Verifikasi Sesi HMAC

getSellerSessionAsync() — Cookie seller_session diverifikasi dengan HMAC SHA-256.

Honeypot & Sanitasi

Field tersembunyi website/honeypot mendeteksi bot. Input disanitasi Zod.

// src/app/api/listings/route.js - POST handler (ringkasan) export async function POST(req) { const ip = getClientIp(req); const ipRl = await rateLimitDistributed(`listing:ip:${ip}`, { limit: 10, windowMs: 600_000 }); if (!ipRl.ok) return rateLimitResponse(ipRl); const body = await req.json(); if (body.website || body.honeypot) return honeypotResponse(); const sessionWa = await getSellerSessionAsync(); if (!sessionWa) return unauthorizedResponse(); const parsedInput = listingInputSchema.safeParse(body); if (!parsedInput.success) return validationErrorResponse(parsedInput.error); // ... lanjut ke moderasi }
3

Moderasi Konten (AI + Deterministik)

Setiap iklan melewati pipeline moderasi dua lapisan di src/lib/moderationRules.js sebelum masuk database.

Lapisan 1: Deterministik

  • • Cek kata kunci terlarang (vape, judi, senjata, dll)
  • • Validasi harga per kategori (CATEGORY_PRICE_LIMITS)
  • • Cek duplikasi judul/deskripsi
  • • Deteksi pola penipuan (harga terlalu murah, dsb)
  • • Instant, zero latency, zero cost

Lapisan 2: Gemini AI

  • • Model: gemini-2.5-flash (Vertex AI)
  • • Prompt terstruktur: JSON strict output
  • • Kategori terlarang: 8 kategori (vape, alkohol, narkoba, senjata, joki, akun game, pornografi, penipuan)
  • • Skor risiko: 0.0 (aman) – 1.0 (berbahaya)
  • • Timeout 6 detik + fallback ke pending
// src/lib/moderationRules.js - Pipeline moderasi export async function moderateListing({ title, description, price, category, type, images, seller_wa }) { // 1. Deterministik (cepat, gratis) const deterministic = checkDeterministicModeration({ title, description, price, category, type }); if (deterministic.status !== 'clean') return deterministic; // 2. AI Moderation (Gemini) const ai = await checkAiModeration({ title, description, price, category, imageUrl: images?.[0] }); if (ai.is_prohibited) return { status: 'rejected', risk_score: ai.scam_risk_score, moderation_reason: ai.reason }; if (ai.scam_risk_score > 0.7) return { status: 'pending', risk_score: ai.scam_risk_score, moderation_reason: 'Perlu review manual' }; return { status: 'approved', risk_score: Math.max(deterministic.risk_score, ai.scam_risk_score || 0.1), moderation_reason: 'Lolos moderasi otomatis' }; }

Persistensi Database & Logika Bisnis

Data yang lolos moderasi disimpan ke tabel listings via service_role. Logika bisnis kompleks dieksekusi: harga, campus, distributor, toko, pembayaran.

Logika Harga & Gratis

  • • adFeeFrom() hitung biaya tayang
  • • Mode gratis: freeMode, Pro, Distributor, Punya Toko
  • • Distributor: fee bagi hasil calcDistributorFee()
  • • Auto-heal profil kampus jika kosong

Status & Pembayaran

  • • active jika gratis / sudah bayar
  • • pending jika butuh QRIS
  • • Tabel payments untuk tracking
  • • Cek tagihan sold_fee belum bayar (blokir akun)
