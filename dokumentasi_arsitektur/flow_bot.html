Bot WhatsApp

Arsitektur bot Baileys multi-device yang berjalan di VPS terpisah, terintegrasi dengan Supabase untuk sinkronisasi real-time data transaksi, broadcast, dan manajemen sesi.

Topologi Deployment

Komponen Inti Bot

Baileys Core (index.js)

  • • Multi-device support — tidak perlu HP utama online
  • • Event-driven — message.upsert, connection.update, creds.update
  • • Signal Protocol — enkripsi end-to-end native
  • • QR Pairing — kode pairing + QR code fallback
  • • Reconnection logic — exponential backoff + offline queue

PM2 Process Manager

  • • Auto-restart — crash recovery, memory limit restart
  • • Cluster mode — opsional untuk scaling horizontal
  • • Log rotation — pm2-logrotate, retain 30 hari
  • • Monitoring — `pm2 monit`, `pm2 list`, metrics endpoint
  • • Startup script — `pm2 startup systemd` untuk persist reboot

Nginx Reverse Proxy

  • • SSL Termination — Let's Encrypt / Certbot auto-renew
  • • Rate Limiting — `limit_req_zone` per IP untuk webhook
  • • WebSocket Proxy — Baileys butuh WS upgrade untuk realtime
  • • Health Check — endpoint `/health` untuk load balancer
  • • Access Log — format JSON untuk parsing analitik

Session Persistence

  • • Auth State — `./auth_info` (creds, keys, signedPreKey)
  • • Backup Cron — `0 3 * * * tar -czf backup/auth_$(date).tar.gz auth_info`
  • • Multi-session — support multi-nomor (bot utama + notifikasi)
  • • Migration Ready — script `cadangkan-sesi.sh` untuk pindah VPS
  • • Conflict Resolution — `conflict: delete` strategy saat pair ulang

Pola Integrasi Bot ↔ Supabase

1 Broadcast Queue (wa_outbox)

Web menuliskan ke tabel `wa_outbox`, bot mem-polling atau menggunakan Realtime untuk mengirim pesan ke grup/nomor target.

// Web (src/lib/fonnte.js) - Enqueue broadcast await supa.from('wa_outbox').insert({ target_type: 'group', // 'group' | 'contact' | 'broadcast' target_id: '120363...@g.us', // JID grup / nomor message: { text: '📦 Iklan baru: MacBook Pro M3...' }, media_url: 'https://...', // optional priority: 1, // 1=high, 5=low retry_count: 0, status: 'pending' }); // Bot (index.js) - Polling worker setInterval(async () => { const { data: queue } = await supa.from('wa_outbox') .select('*').eq('status', 'pending').lte('retry_count', 3) .order('priority').order('created_at').limit(10); for (const msg of queue) { await sendMessage(msg.target_id, msg.message); await supa.from('wa_outbox').update({ status: 'sent', sent_at: new Date() }).eq('id', msg.id); } }, 5000);

2 Transaction Sync (Real-time)

Bot mendengarkan perubahan pada tabel `payments` dan `listings` via Supabase Realtime untuk notifikasi instan ke penjual/pembeli.

// Bot (index.js) - Realtime subscription supa.channel('payments_changes') .on('postgres_changes', { event: 'INSERT', schema: 'public', table: 'payments', filter: 'type=eq.iklan' }, payload => { const payment = payload.new; notifySeller(payment.seller_wa, `💰 Pembayaran iklan diterima: ${payment.amount}`); }) .subscribe(); supa.channel('listing_status') .on('postgres_changes', { event: 'UPDATE', schema: 'public', table: 'listings', filter: 'status=in.(active,sold,rejected)' }, payload => { const listing = payload.new; notifyOwner(listing.seller_wa, `📢 Iklan "${listing.title}" sekarang ${listing.status}`); }) .subscribe();

3 Admin Commands via WA

Admin bisa mengelola sistem lewat WhatsApp dengan command terstruktur (prefix `!` atau `/`).

// Bot (index.js) - Command handler const adminCommands = { 'stats': async (msg) => { const { count: users } = await supa.from('seller_profiles').select('*', { count: 'exact', head: true }); const { count: listings } = await supa.from('listings').select('*', { count: 'exact', head: true }); return `📊 Stats: ${users} users, ${listings} listings`; }, 'broadcast': async (msg, args) => { const text = args.join(' '); await supa.from('wa_outbox').insert({ target_type: 'broadcast', message: { text }, priority: 1, status: 'pending' }); return `📢 Broadcast dikirim ke semua grup`; }, 'ban': async (msg, args) => { const wa = formatWa(args[0]); await supa.from('blacklist').insert({ wa, reason: args.slice(1).join(' ') || 'Manual ban' }); return `🚫 ${wa} dibanned`; }, 'unban': async (msg, args) => { const wa = formatWa(args[0]); await supa.from('blacklist').delete().eq('wa', wa); return `✅ ${wa} unbanned`; } }; // Message handler sock.ev.on('messages.upsert', async ({ messages }) => { for (const msg of messages) { if (!msg.message?.conversation) continue; const text = msg.message.conversation.trim(); if (text.startsWith('!') && isAdmin(msg.key.remoteJid)) { const [cmd, ...args] = text.slice(1).split(' '); if (adminCommands[cmd]) { const reply = await adminCommands[cmd](msg, args); await sock.sendMessage(msg.key.remoteJid, { text: reply }); } } } });

4 Health Monitoring & Alerting

Bot mengirim heartbeat berkala dan alert ke admin jika terjadi anomali (koneksi putus, error berulang, memory tinggi).

// Bot - Heartbeat & Health Check setInterval(async () => { // 1. Update status bot di DB await supa.from('bot_status').upsert({ id: 'main_bot', status: 'online', last_seen: new Date(), memory_mb: Math.round(process.memoryUsage().heapUsed / 1024 / 1024), uptime_sec: Math.round(process.uptime()), version: require('./package.json').version }); // 2. Check Supabase connectivity try { await supa.from('bot_status').select('id').limit(1); } catch { await alertAdmin('🚨 Bot tidak bisa konek ke Supabase!'); } // 3. Alert jika memory > 500MB if (process.memoryUsage().heapUsed > 500 * 1024 * 1024) { await alertAdmin(`⚠️ Memory tinggi: ${Math.round(process.memoryUsage().heapUsed/1024/1024)}MB`); } }, 60000); // setiap 1 menit // Admin alert via WA async function alertAdmin(text) { const adminWa = process.env.ADMIN_WA || '6281234567890@s.whatsapp.net'; await sock.sendMessage(adminWa, { text: `[ALERT] ${text}` }); }
